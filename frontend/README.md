# URL2Vid - Frontend

A minimal, responsive React (Vite) frontend for fetching and downloading videos.

## How to run
1. `npm install`
2. `npm run dev`

## Environment Variables
- `VITE_API_BASE_URL`: Base URL for the backend API (e.g. `http://localhost:3001`). If not set, defaults to `http://localhost:3001` in the code.
